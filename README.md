## About
Changelog Writer is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **Developer Tools**.

## Features
- Commit/PR list → categorized release notes (features, fixes, breaking)
- Tone presets: developer, marketing, executive
- Semantic version suggestion from change types
- Export to Markdown, HTML or Keep-a-Changelog format
